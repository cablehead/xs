## Install

### brew

```sh
brew install cablehead/tap/cross-stream
```

Optionally start the store as a background service:

```sh
brew services start cablehead/tap/cross-stream
```

### eget

```sh
eget cablehead/xs
```

### cargo

```sh
cargo binstall cross-stream
```
